# paper-companion · 论文阅读搭档

一个给 AI 用的 skill。你丢给它一篇论文、技术文档或开源项目,它把内容拆到最底层的问题,用大白话重讲一遍,再告诉你**这对你自己的工作意味着什么**。

它不是"论文总结工具"。总结告诉你论文说了什么;它多做三件事:

- **讲到外行能复述。** 先交代场景,例子先行,一个发现只给一个数字,其余放附表。
- **以你为准判断相关性。** 你是做什么的、在做什么项目、关注什么主题,第一次用时它会问,之后每篇报告都按这个来判断"强相关、弱相关还是几乎无关"。
- **不编。** 提到的前人工作先核实,没把握的明说;关键结论标出处;答不上的问题写"论文未回答"。

## 安装

需要一个能读写文件的 AI 编程工具。下面以 Claude Code 为例。

**第一步:选一个固定的文件夹。** 以后都在这个文件夹里用它(原因见下文「请固定在同一个文件夹里用」)。

**第二步:把本仓库放进这个文件夹的 `.claude/skills/paper-companion/`。**

```bash
git clone https://github.com/Qysun54/paper-companion.git .claude/skills/paper-companion
```

不想敲命令的话,把仓库地址发给你的 AI,说"把这个 skill 装到当前文件夹"也可以。

**第三步:重新打开 Claude Code,丢一篇论文给它。** 给 PDF 路径或链接都行,说"读一下这篇"。

**目前只在 Claude Code 上完整测试过,其他工具的用法仅供参考。** 用别的工具(Codex、Cursor 等):把整个文件夹放到该工具读取 skill 的位置;没有 skill 机制的,对 AI 说"按这个文件夹里的 SKILL.md 执行"。

你**不需要改 SKILL.md**。所有和你个人有关的内容,都由它第一次用时问出来、自己存好。

## 第一次用会问你什么

第一次触发时,它先问四个问题,然后才开始读:

1. **你是做什么的?** 一句话。只有这一问必答。
2. **当前在做什么项目?** 越具体,相关性判断越准。没有可以跳过。
3. **想持续关注哪几个主题?** 每个主题是一个"主题包",读过的和待读的都按包归类。先填一两个就行。
4. **读完后希望准备好回答哪几类人的问题?** 默认三类:懂技术的同事、同行、上级。可以增减、改名。

答案存在你文件夹里的 `个人设定.md`,不会进入这个仓库。以后想改,说一句**"改一下我的设定"**就行,不用手动编辑文件。

## 请固定在同一个文件夹里用

设定、读过的报告、认知地图、摘录都存在你第一次使用时所在的文件夹里。

**换一个文件夹,它会重新问一遍设定,之前读过的资料也不会带过去。** 所以请选定一个文件夹,以后一直在那里用。

用久了,这个文件夹里会有这些东西(这些都在你自己的文件夹里,不在仓库里):

| 文件 | 是什么 |
| --- | --- |
| `个人设定.md` | 四个问题的答案 |
| `papers/` | 每篇报告一个文件 |
| `shorts/` | 每篇报告配一个短片(网页文件,双击打开) |
| `认知地图.md` | 读过的东西之间的关系图、索引表、待读清单 |
| `提问清单.md` | 每类人会问的问题,可以换成你被问过的真实问题 |
| `摘录.md` | 你高亮过的句子 |

## 有哪些功能

| 功能 | 怎么用 | 说明 |
| --- | --- | --- |
| 精读一篇 | 给 PDF 或链接,说"读一下这篇" | 论文、技术文档、开源项目都可以 |
| 认知地图 | 自动 | 每读一篇,更新关系图、索引表和待读清单 |
| 和已读的放在一起看 | 自动 | 读过相关的东西时,报告里多一节讲它们合起来怎么用 |
| 角色问答 | 自动 | 报告末尾按 `提问清单.md` 逐条作答;答不上的写"论文未回答" |
| 论文短片 | 自动 | 最多五个镜头,每格一句大白话 |
| 包综合 | 自动 | 一个主题包全部读完时,出一份立场地图和总问答 |
| 高亮 | 对话里说"高亮:某句话" | 存进 `摘录.md`。它会先核对这句话是不是原文里逐字有的 |
| 改设定 | 说"改一下我的设定" | 提问清单和待读分组会跟着更新 |
| 选中高亮 | 说"帮我装上选中高亮" | **仅 macOS**,见下一节 |

每篇报告交付前,它会另起一个没读过原文的 AI 当"陌生读者"把报告读一遍,检查有没有外行看不懂的地方。所以读一篇比普通总结慢,这是有意的。

## 仅 macOS 可用的功能:选中高亮和备忘录同步

**这两样是一起安装的。** 没安装时,对话里说"高亮:"只存进 `摘录.md`,不会进备忘录。

装上之后:

- 在别的应用里选中一段字,触发系统服务「高亮到论文摘录」,这段字就存进 `摘录.md`,同时在「备忘录」的「论文摘录」文件夹里记一条,经 iCloud 同步到手机。
- 对话里说"高亮:"的那些,也会同步进备忘录。

**安装条件**:macOS,而且「备忘录」登录了 iCloud 账户。对 AI 说"帮我装上选中高亮",它会先检查这两条,满足才装,装完带你试一次。不满足会告诉你原因,对话里的高亮照常可用。

**如实说明的限制**:

- **能右键用的**:用系统自带右键菜单的应用,比如预览、Safari、备忘录、文本编辑。选中 → 右键 → 服务 → 高亮到论文摘录。
- **右键里没有这一项的**:右键菜单是应用自己画的,比如 Claude 桌面应用、VS Code、Cursor。只能:选中 → 屏幕顶部菜单栏的应用名 → 服务;或者自己设一个快捷键,选中后按快捷键。
- **快捷键要你自己设**:系统设置 → 键盘 → 键盘快捷键 → 服务 → 文本 → 高亮到论文摘录。AI 不会替你改系统设置。
- **第一次运行可能要再点一次允许**:安装时的许可是给终端的,系统服务是另一个程序。备忘录没写进去时,到 系统设置 → 隐私与安全性 → 自动化 里打开对应的开关。
- **个别应用用不了**:有的应用不把选中的文字交给系统服务。以装完当场试的结果为准。
- **一台电脑只指向一个文件夹**,就是安装时的那个。文件夹挪了位置要重装。
- **Windows、Linux、网页版**:只能用对话里的"高亮:"。

卸载:说"卸掉选中高亮"。已有的摘录和备忘录不会被删。

## 想每周自动收到新论文:自己建一个定时任务

这个 skill **不负责找论文**,只负责读。想定期收到新论文,可以另建一个每周定时任务:**它负责找,skill 负责读。**

在 Claude Code 里可以让 AI 帮你建定时任务;用别的工具,任何能定时运行一段提示词的方式都行。下面是一段可以直接用的任务描述,把【】里的内容换成你自己的:

```text
每周【星期几、几点】执行一次。工作文件夹:【你固定使用的那个文件夹的完整路径】。

目标:为我找本周值得读的新论文或技术文章,最多【3】篇。

我关注的主题(每行一个):
【主题一】
【主题二】

去哪找:【例如 arXiv 的某几个分类、某几个博客、某几个会议。不填则由你决定,但要告诉我你去了哪里找】

筛选规则:
1. 只要最近【7】天内发布的。
2. 每篇给出:标题、链接、发布日期、一句话说明它和我的哪个主题有关。
3. 链接必须真的打开核对过。打不开、或者拿不准是不是真有这篇的,不要列。宁可少,不要编。
4. 先读工作文件夹里的 认知地图.md,已读或已在待读清单里的不要重复推荐。

做完后:
1. 把入选的追加到 认知地图.md 待读清单里对应的主题包下,「牵出 / 入选理由」一栏写"每周推送"。
2. 把清单发给我。
3. 不要自己开始精读。等我说"读一下第 N 篇"时,再用 paper-companion skill 来读。

如果工作文件夹里还没有 个人设定.md,说明我还没用过 paper-companion:不要推送,提醒我先在对话里读一篇、完成首次设定。
```

两点提醒:

- **先手动读过一篇再建定时任务。** 定时任务运行时没有人可以问,而 skill 第一次用需要问你四个问题。
- **主题写得越具体,推送越准。** "AI"太宽;"怎么评估 AI 输出的质量"就好得多。

## 仓库里有什么

| 文件 | 是什么 |
| --- | --- |
| `SKILL.md` | 全部规则。唯一的现行版本 |
| `提问清单-默认.md` | 默认的三类角色和通用问题,首次设定时照它建你自己的 `提问清单.md` |
| `paper-short-template.html` | 短片模板。生成短片时只改里面的一组镜头数据 |
| `install-highlight.sh` | 「选中高亮」的安装脚本,仅 macOS |
